# ICS55 ECOS SRAM

Generated single-port SRAM integration packages for the ICS55 55nm process.

## Download

Download packages from the [Releases page](https://github.com/openecos-projects/ics55_ecos_sram/releases).

Choose the `.tar.gz` asset named for the SRAM instance. GitHub's automatically generated **Source code** archives contain this repository's documentation.

## Package scope

Each package contains the integration views for one SRAM instance. Use it with the matching ICS55 PDK. Check the release page for included views, operating corners, rights, and permitted use.

## Naming

The repository name follows the [open-pdks IP naming convention](https://github.com/fossi-foundation/open-pdks#ip-naming-conventions) `<pdk-family>_<provider-tag>_<kind>`: `ics55_ecos_sram`.
