# ICS55 ECOS SRAM

Generated single-port SRAM integration packages for the ICS55 55nm process.

## Configure and download

Use the [ECOS Factory SRAM Compiler](https://factory.openecos.com/ip/sram) to
configure an SRAM instance and download its package.

## Repository scope

This repository stores packages generated by ECOS Factory. Each `.tar.gz`
release asset is named for one SRAM instance and contains its integration views.
Use it with the matching ICS55 PDK; the release metadata lists the included
views, operating corners, and applicable terms.

## Naming

The repository name follows the [open-pdks IP naming convention](https://github.com/fossi-foundation/open-pdks#ip-naming-conventions) `<pdk-family>_<provider-tag>_<kind>`: `ics55_ecos_sram`.
